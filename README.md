# JOOP Engineering Website

This is a responsive multi-page website for **JOOP Services & Engineering Works**, designed to showcase the company's services, products, mission, and contact information.

## 🌐 Overview

The website includes the following pages:
- **Home** – Hero banner, company highlights, client testimonials.
- **About Us** – Company background, mission, vision, values, and overview.
- **Projects** – Overview of key Projects and solutions.
- **Services** – Core engineering services provided by JOOP.
- **Contact** – Contact form, company email, and social links.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **Bootstrap Icons**
- **FormSubmit** – For sending contact form submissions to email.
- **Custom assets** – Backgrounds, logos, and patterns.

## 📬 Contact Form Integration

The contact form uses [FormSubmit](https://formsubmit.co/) to send messages to the company email address:
```html
<form action="https://formsubmit.co/markomondi101@gmail.com" method="POST">
```

## 🔒 Security Notes
Avoid placing any sensitive credentials directly in the HTML.

Make sure to use HTTPS when deploying the site.
